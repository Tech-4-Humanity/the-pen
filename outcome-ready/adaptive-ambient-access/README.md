## Overview

Adaptive Ambient Access (AAA) is an NDIS SaaS capability layer that delivers always-on, low-friction support access for participants. It removes the need for participants to actively initiate every support interaction by using contextual triggers, ambient presence signals, and pre-authorised support windows.
