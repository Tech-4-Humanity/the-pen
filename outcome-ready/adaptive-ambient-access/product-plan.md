# Adaptive Ambient Access — Product Plan

**Version:** 1.0  **Project:** OR-AAA-001

## Problem

NDIS participants with high support needs struggle to initiate support at the moment they need it. Existing tools require active engagement at exactly the wrong time — during distress, fatigue, or cognitive overload.

## Solution

AAA delivers pre-configured, ambient support access that activates through:
- Scheduled windows (participant-defined)
- Contextual triggers (location, time, routine patterns)
- Carer/coordinator pre-authorisation
- Low-signal inputs (single tap, voice keyword, wearable trigger)

## Target Users

| Segment | Description |
|---|---|
| High-needs participants | Daily support, complex disability profiles |
| Coordinators of support | Managing multiple participants remotely |
| Registered providers | Delivering AAA as a compliant service module |

## Core Features

1. **Ambient windows** — pre-authorised time blocks with auto-connect
2. **Trigger rules** — condition-based support activation
3. **Presence signals** — soft check-ins without explicit action
4. **Audit trail** — NDIS-compliant support delivery log
5. **Carer dashboard** — real-time ambient status view

## Success Metrics

- Time-to-support < 10s from trigger
- 0 missed critical support windows in pilot cohort
- NDIS audit pass rate 100%
- Participant-reported effort score < 2/10
