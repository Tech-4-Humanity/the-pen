# The Day the Organisation Learned to Live

## Status

FOUNDATIONAL BOOK PACKAGE — v0.9

## Purpose

This directory contains the canonical foundation for the Organisational Evolution book programme.

The book explains how organisations move from hierarchy, through augmentation and capability networks, toward living organisations and regenerative ecosystems.

## Canonical structure

- `manuscript.md` — current canonical manuscript
- `book-architecture.md` — publication structure and chapter plan
- `canonical-glossary.md` — controlled terminology
- `research-propositions.md` — testable propositions and evidence agenda
- `publication-assets.md` — figures, pull quotes, infographic and messaging register
- `manifest.json` — machine-readable package metadata

## Conceptual hierarchy

1. Organisational Evolution Theory — why organisations evolve
2. Organisational Evolution Framework — how evolution unfolds
3. Organisational Evolution Canon — what humanity learns during the journey
4. OIKOS — the living organisation model
5. Runtime — governed execution substrate

## Evolutionary engine

Purpose → Pressure → Adaptation → Selection → Capability → Learning → Memory → Evolution → Flourishing

## Publication destination

The completed book is intended for publication through AI Era Thinking.

## Quality rule

The manuscript must distinguish observed evidence, theoretical reasoning, hypotheses, normative claims and aspiration. Unsupported numerical claims are excluded until evidence exists.
