## UX and UI enhancement opportunities

### Priority 1 — Command Centre Home

Current hub is functional but still link-heavy.

Upgrade to:

- three lanes: Today / Transition / Tomorrow
- visual progress states
- AHC Droid hero identity
- board-safe summary line
- quick print button
- latest update / last commit badge

### Priority 2 — Interactive Top 20 Atlas

Create manual-input v2 before connector automation.

Features:

- paste CSV or JSON
- sort by revenue, margin, risk, expansion potential
- show concentration risk
- map each customer to future workforce markets
- label data as Actual, Assumption, or Scenario

### Priority 3 — Interactive Question Atlas

Upgrade static 5 → 12 → 60 page.

Features:

- tabs for Five / Twelve / Sixty / Diligence
- filter by Alan, Board, Owner, CFO, Customer
- print mode
- favourite/starred questions
- meeting mode with 10-minute and 30-minute versions

### Priority 4 — Evidence State Tags

Every claim should show:

- Proven
- Briefing says
- Assumption
- Scenario
- Data needed

This prevents seeded future-state data from being confused with real evidence.

### Priority 5 — Board Mode / CEO Mode Toggle

Same content, different emphasis.

Board Mode:

- risk
- governance
- cash
- value
- downside

CEO Mode:

- day one
- customers
- people
- operating rhythm
- decisions

### Priority 6 — Print Pack Upgrade

Current Print Pack is an index.

Upgrade to:

- one-click print sequence

- board pack checklist
- interview pack checklist
- diligence pack checklist

### Priority 7 — Market Opportunity Layer

Seeded scenarios are acceptable if clearly labelled.

Add scenario data for:

- AI Infrastructure Workforce
- Agent Workforce

Each scenario should include:

- target buyer
