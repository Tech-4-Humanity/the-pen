# Submission outputs — gated

This directory will hold privacy-safe build instructions, redacted previews, manifests and final output hashes.

## Placeholder outputs

- `ato-submission/`

- `additional/`

## Gate

No document belongs here as a final output until:

1. every figure is reconciled;
2. every material claim is linked to primary evidence;
3. contemporaneous, reconstructed and modeled evidence are labelled separately;
4. source files have stable storage URIs and SHA-256 hashes;
5. the generated file passes structural and visual QA;
6. independent readback matches the expected output;
7. a receipt records inputs, output hash, validation and remaining gaps.

Confidential source binaries must not be committed to this repository.
