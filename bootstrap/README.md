# Bootstrap

This directory holds product bootstrap doctrine and per-product activation files.

## Operating intent

- House Rules Engine is **Product 1**.
- Product Loop doctrine applies to all future products.
- Every product must include post-production layers: storage, bootstrap, distribution, evidence, feedback, automation, scaling, governance, recovery, monetisation, replication, and uplift.
- Use **nine views** for product review: signal, consent, governance, orchestration, execution, outcomes, distribution, revenue, experience.
