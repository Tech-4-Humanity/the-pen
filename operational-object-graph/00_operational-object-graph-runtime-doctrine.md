## Core Correction
The centre is not Holo-Org. The centre is the Operational Object Graph.

Holo-Org becomes the visualisation and orchestration shell around the graph. Factor becomes the memory substrate. MRI becomes the interpretation layer. Command Centre becomes the human and agent operating surface.

## Category Thesis
Most companies store records. This system stores organisational reality.

The durable asset is not dashboards, AI chat, workflow tooling, or vertical SaaS skins. The durable asset is:

- canonical operational objects
- evidence lineage
- cross-system continuity
- agent-readable memory
- governed truth states
- reconstructable organisational reality

- object type
- source system
- confidence score

- event history
- consent state

- monetisation or outcome link
