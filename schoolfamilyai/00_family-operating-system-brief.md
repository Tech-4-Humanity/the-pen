# SchoolFamilyAI / Family Operating System — Build Brief

## Status
PARTIAL — strategic build pack created and committed to canonical Pen repo. Runtime Bridge execution still requires bridge worker receipt.

## Result
SchoolFamilyAI is defined as the longitudinal operating system for learning, wellbeing, family operations, practitioner coordination, school communication, and future workforce readiness.

It is not a kids app. It is the orchestration layer between:
- child
- parent / guardian
- teacher
- school leader
- tutor
- therapist / practitioner
- support worker
- AI tutor
- wellbeing companion
- community programs
- future workforce pathways

## Core Position
The system competes against fragmented child-development infrastructure, not against homework apps.

Current market fragmentation:
- LMS
- homework tracker
- reading app
- behaviour app
- therapy notes
- family calendar
- school comms
- tutor notes
- wellbeing check-ins
- NDIS / intervention records

SchoolFamilyAI unifies these under a permissioned, longitudinal, consent-governed development graph.

## Strategic Moat
The moat is not AI. The moat is:
- longitudinal context
- adaptive learning profile
- trusted consent graph
- multi-actor coordination
- outcomes and intervention evidence
- child-safe AI continuity
- institution-ready governance
- parent/teacher/practitioner workflow integration
