# Portfolio Dossier Factory v1.0

Status: PARTIAL

This file locks the one-business-per-page standard for Troy Latter's live and under-development business portfolio.

## Operating rule

One business equals one dossier page. No five-up sheets as master assets.

Each dossier must use the same structure, same visual grammar, same maturity model, and same quality bar.

## Canonical page structure

1. Business name
2. Domain or primary URL
3. Status
4. Category
5. Owner
6. Stage
7. Hero screenshot or product UI image
8. What is it?
9. The problem
10. Target customers
11. Key capabilities
12. Customer outcomes
13. Revenue streams
14. Ecosystem position
15. Strategic role
16. Competitive advantage
17. Maturity score
18. 12-month target
19. Connected brands
20. Footer: industry, target market, delivery model, pricing model, QR/link

## Quality standard per individual page

A page passes only if it scores at least 8/10 against each of these:

- Clarity: reader understands business in 20 seconds
- Commerciality: revenue path is explicit
- Customer definition: primary, secondary, future customer are named
- Ecosystem fit: position inside Tech 4 Humanity/AHC/Outcome Ready stack is visible
- Evidence readiness: status is not overstated
- Visual consistency: same grid, same hierarchy, same density
- Screenshot quality: real website screenshot preferred; generated UI only allowed as placeholder
- Searchability: business name, URL, category, customer, revenue model and tags must be stored as text metadata
