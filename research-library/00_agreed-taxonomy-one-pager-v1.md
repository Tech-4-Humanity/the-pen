## Purpose

Before anything is cut, frozen, merged, killed, or promoted, this one-pager defines the working shape of the research estate.

The key correction is that there is no single magic count. The research library has multiple valid views:

- public poster / exhibit view
- research programme view
- theme view
- topic view
- subtopic view
- emerging / extras view
- killed / merged / parked view
- Integrity Stack view
- Doolittles translation view
- commercial / audit view

The final decision list must preserve all of those views without pretending they are the same thing.

## What is killed?

Current evidenced answer: not enough information yet to assign honest killed counts by area.

Working rule:

- KILLED = false, weak, unsafe, off-strategy, duplicate without value, or not worth carrying.
- MERGED = useful but absorbed into a stronger parent topic.
- PARKED = interesting but no current evidence, commercial route, or priority.
- EMERGING = not accepted yet, but worth keeping alive.
- KEEP = accepted into v1 taxonomy.
