# CCOS Governance

1. Search before creating a new communication object.
2. Reuse one canonical object with variants instead of duplicating content.
3. Material changes increment version and preserve provenance.
4. Missing required variables cause validation failure; facts are never silently invented.
5. Legal, financial, regulatory, privacy, employment, safety and public-policy claims require declared review.
6. Templates and examples must not contain credentials, secrets or unnecessary personal information.
7. Generated output is PARTIAL until validated. Sent output is not REAL without a receipt.
