# Synal — Visual Baseline Image Direction

## Purpose
Lock the current Synal hero image as the visual baseline for the communication suite: premium, multi-surface, one-command coordination with Doolittles embedded as the translation module.

## Core image message
One command. Every surface. Every system.

## Product relationship shown
- Synal = communication suite and multi-surface command layer.
- Doolittles = translator/conductor module inside Synal.
- HoloWall = TV/shared proof surface.
- AHC / WorkFamily AI = human coaching and translation support.
- Widgets = operating modes inside Synal browser.

## Visual elements to preserve
- Large SYNAL brand on left.
- Strong headline: One command. Every surface. Every system.
- Doolittles character as translator, not master brand.
- Central command bubble: optimise the next 90 days for impact, profit and purpose.
- Signal lines from one command to many tools/surfaces.
- Enterprise tools: Slack, Email, Salesforce, ServiceNow/PM, Databases.
- Physical/personal surfaces: TV/HoloWall, Mobile, Car, Smart Speaker, Coffee Machine, Supply Chain, Pets/Family Signals.
- Laptop browser showing Synal widgets: Snaps, Threads, Pulse, Focus, Flows, PR Memory, Doolittles.
- Mobile approval/action surface.
- Car dashboard continuation.
- HoloWall readiness board with readiness %, impact, time saved, tasks completed.
- Proof and memory strip: One Command, Unified Intelligence, Real-Time Action, Proof & Memory, Private & Secure.

## What the image proves
The same command reaches:
- people;
- enterprise software;
- personal devices;
- shared spaces;
- machines;
- family/wellbeing contexts;
- supply chain/logistics;
- agent pods.

This image turns Synal from a browser concept into a multi-surface communication suite.
