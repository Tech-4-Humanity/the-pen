# Synal + Doolittles — Brand Architecture

## Decision
The communication tool suite is Synal.

Doolittles is the friendly product layer, demo language, character/metaphor and adoption wrapper inside Synal.

## Brand hierarchy

### Master suite
Synal

Purpose:
- communication suite;
- signal routing;
- command layer;
- widgets/apps/extensions;
- multi-surface presence across browser, mobile, TV, car, room, laptop and other places.

### Product / demo layer
Doolittles

Purpose:
- make Synal understandable;
- show humans and machines hearing the same thing in their own language;
- provide playful but useful demos;
- create partner stories: Slack, ServiceNow, Salesforce, SAP, Microsoft, LMS, HRIS.

### Character / metaphor
Dr Doolittle / Doolittles

Purpose:
- talk to the animals/tools/systems;
- explain the tool zoo;
- make complex organisational translation obvious.

### Underlying operating system
T4H Command Layer

Purpose:
- execution, registry, roles, signals, assets, states, proof and governance.

---

## Positioning

Synal is the communication suite.
Doolittles is how people understand what Synal does.
Command Layer is how it runs.
HoloWall is how it is seen.
AHC is how people are coached through it.

## Core line
Synal delivers the signal. Doolittles translates it. Command Layer acts on it. HoloWall proves it.

---

## Product family

### Synal Browser
A new-style browser / command surface with widgets and extensions.

Widgets/apps:
- Snaps by Comet;
- PR Memory;
- Stickies;
- Spirals;
- Threads;
- Pulse;
- Focus;
- Flows;
- Doolittles;
- HoloWall;
- Agent Channel;
- Command Layer.

### Synal Mobile
Mobile signal surface for notifications, commands, approvals, and personal preference delivery.

### Synal TV / HoloWall
Shared-room visual surface for readiness, signals, status and organisational movement.

### Synal Vehicle / Car Surface
Context-aware mobile environment for alerts, preparation, scheduling and voice-driven commands.

### Synal Room / Space
Office, clinic, classroom or workplace surface where people and systems share status.

### Synal Extension Pack
Browser extensions and widgets that make existing tools Doolittles-aware.

---

## Doolittles inside Synal

Doolittles appears as:
- a widget;
- a demo mode;
- a command translator;
- a tool-zoo visual layer;
- a partner integration story;
- a neuroinclusive communication module.

Doolittles does not replace Synal. It makes Synal memorable.
