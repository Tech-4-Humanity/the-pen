What it is

Capability without model lock-in.

T4H Agent OS separates the workforce definition from the model that executes it. Qwen, Ollama-hosted models or any compatible command can serve as a provider. The product is the registry, job lifecycle, governance and evidence—not a model brand.

Agents are not permanently running personalities. An event creates a job; a worker claims it; the selected specialist receives bounded context; validated output and telemetry become receipts.

Economics

Cost belongs to the job.

V1 captures provider, model, duration and exit code. V1.1 adds input/output tokens, model charge, tool charge, infrastructure allocation, retries, customer, revenue attribution and total cost. Local models are low marginal cost—not zero cost.

Truth is structured.

REAL requires terminal execution, validation and receipts. It does not automatically make the model's underlying claim true; high-risk work requires independent verification or an arena.
