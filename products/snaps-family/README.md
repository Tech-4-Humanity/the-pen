# Snaps / AgentSnaps / SuperSnaps

This folder contains the authoritative handoff package for the browser-led unfinished work product family.

## Product ladder
- **Snaps** = browser-led capture product
- **AgentSnaps** = worker-attached mode on top of Snaps
- **SuperSnaps** = closure, governance, recovery, and proof layer across the family

## Core doctrine
A Snap is not a saved tab set.
A Snap is a browser-originating unit of unfinished or finishable work.

## Boundary rules
- Everything in Snaps is included in AgentSnaps and SuperSnaps.
- Everything in AgentSnaps is included in SuperSnaps.
- This family is browser-led. It is **not** the universal ingest product for all work across the whole ecosystem.

## Files
- `SNAPS_FAMILY_HANDOFF.md` — full product, feature, doctrine, and governance handoff for Pen.

## Instruction to Pen
Do not start fresh.
Start from existing Snaps artefacts, language, flows, and assumptions already in play, then extend and reconcile them into the structure defined in the handoff.
