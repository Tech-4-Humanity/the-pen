# Hakuna Matata Lossless Harvest v4

This folder is the shared, appendable source-control surface for the Hakuna Matata table-of-tables harvest.

## Purpose

Preserve every discovered workbook, registry, catalogue, dossier, schema, runtime artefact and research source before canonical reconciliation.

## Rules

1. Never delete source evidence.
2. Preserve exact Drive file IDs, GitHub paths, commit refs and source versions.
3. Append source records before extracting rows.
4. Keep duplicates and conflicting values until evidence-based alias or supersession decisions are recorded.
5. Do not invent missing values.
6. Distinguish source-reported counts from extracted and verified counts.
7. Every extraction requires a receipt: source pointer, version/ref, row count, output path, verification date and operator/worker.
8. Workbook, CSV and GitHub views are generated surfaces of the same ledger; none may silently replace another.
