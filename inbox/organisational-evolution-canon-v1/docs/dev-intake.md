# Developer Intake Handover

## Status

**PARTIAL / DEPLOY-READY STATIC ASSET**

The bundle is complete for static deployment and design iteration. It does not claim empirical validation, production telemetry or integration with the Runtime Kernel.

## Intent

Publish a clear public explainer that:

1. Places human flourishing above technology.
2. Separates Theory, Framework and Canon.
3. Makes the evolutionary engine the centrepiece.
4. Positions OIKOS as the Living Organisation Model.
5. Positions Runtime as technical implementation doctrine.
6. Avoids unsupported numerical claims.

## Required outcome

A responsive, accessible page that works without a build step or external dependency.

## Acceptance criteria

- [x] Runs from a static file server.
- [x] Contains no external JavaScript or CSS dependency.
- [x] Responsive at desktop, tablet and mobile widths.
- [x] Keyboard-accessible stage cards.
- [x] Reduced-motion preference respected.
- [x] Theory, Framework and Canon definitions visible.
- [x] Evolutionary engine contains Purpose, Pressure, Adaptation, Selection, Capability, Learning, Memory, Evolution and Flourishing.
- [x] Surrounding ecosystem includes People, AI, Organisations, Communities, Governments and Nature.
- [x] OIKOS and Runtime are clearly separated.
- [x] Unsupported impact multipliers omitted.

## Deployment targets

Preferred:

- S3 + CloudFront

Compatible:

- GitHub Pages
- Static web server
- Existing portfolio microsite shell

## Suggested production path

1. Review canonical language.
2. Approve public naming and trademarks.

7. Add evidence register links as research is validated.

## Non-goals for v1

- No SaaS application.
- No maturity scoring engine.
- No user accounts.
- No autonomous agent execution.
- No claim that the five states are inevitable or universally sequential.
- No exact economic multipliers without evidence.
