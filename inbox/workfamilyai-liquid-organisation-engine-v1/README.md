# WorkFamilyAI Liquid Organisation Engine v1

Interactive and predictive operating layer for the 10x10x10 WorkFamilyAI organisational runtime.

## Purpose
Turn 1,000 role records into an assessment, scenario and prediction system that explains how an organisation currently operates, where AI creates sweet spots or blackspots, how pressure changes the organisation, and which interventions improve flourishing without eliminating humans.

## Core model
The engine combines:
- 10 organisational variables
- 1,000 role records
- artefact, tempo, KPI, dependency and evidence data
- Organisational Evolution states
- AI Sweet Spots and AI Blackspots
- interactive questions
- counterfactual scenarios
- predictive outputs with explicit confidence and evidence

## Human invariant
No human is eliminated. Automation recommendations must preserve accountable human authority, appeal, contestability, dignity and meaningful contribution.

## Included
- canonical specification
- variable model
- assessment question bank
- scenario library
- prediction schema
- UI/runtime requirements
- developer intake plan

## State
Deploy-ready specification and data model. Application implementation, telemetry calibration and validated prediction coefficients remain separate execution work.
