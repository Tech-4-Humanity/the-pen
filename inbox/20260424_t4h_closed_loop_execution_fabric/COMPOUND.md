# /compound — Autonomous Golden Loop Compounding Mandate

## Objective
Turn the autonomous golden loop from a single operating cycle into a compounding growth system across execution, revenue, learning, distribution, and portfolio replication.

## Compounding Formula

```text
Proof x Distribution x Revenue x Learning x Replication = Compound Advantage
```

## Core Loop

```text
Sense -> Decide -> Act -> Prove -> Monetise -> Learn -> Scale -> Repeat -> Compound
```

## What Compound Means
A loop is not compound because it repeats. It compounds only when each cycle improves the next cycle.

Each cycle must increase at least one of:

- execution reliability
- revenue per execution
- conversion rate
- lead quality
- proof quality
- automation coverage
- portfolio reuse
- customer trust
- partner leverage
- margin

- No loop closes without a receipt.
- No receipt is idle; every receipt becomes a sales asset.
- No sales asset is idle; every asset enters distribution.
- No distribution is idle; every response updates targeting.
- No targeting is idle; every insight updates the next loop.
