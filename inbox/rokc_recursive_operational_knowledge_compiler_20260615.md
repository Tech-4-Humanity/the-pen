# Recursive Operational Knowledge Compiler (ROKC)

## Classification
- Evidence state: PARTIAL

## Canonical Definition
The Recursive Operational Knowledge Compiler is a runtime-native institutional cognition engine that continuously transforms operational reality into executable organisational intelligence through recursive compilation, telemetry-bound verification, graph cognition, governance enforcement, and survivable runtime learning.

## Problem
Knowledge, decisions, failures, telemetry, and evidence are fragmented across chats, systems, repositories, dashboards, and people. Organisations repeatedly rediscover the same lessons.

## Core Loop
Observe → Extract → Structure → Reinforce → Execute → Verify → Recompile

- Operational: GitHub, Supabase, queues, receipts, audit logs
- Runtime: failures, retries, replay events, telemetry, survivability metrics
