# ACHRA Assessment Pack

ACHRA means AI Cognitive Friction and Human-Agent Readiness Assessment.

This folder contains the implementation pack for a survey, scoring model, action engine, data model, API contract, widget specification, report template and bridge handoff.

Status: DISPATCH_READY

Core outcome: turn AI adoption friction into measurable scores and useful action paths for individuals, teams and enterprises.

Files in this pack:

- 01_model.md
- 02_survey_items.csv
- 03_scoring_schema.json
- 04_intervention_rules.json
- 05_supabase_schema.sql
- 06_api_contract.md
- 07_widget_spec.html
- 08_report_template.md
- 09_bridge_payload.json
- 10_receipt.json

Execution path:

Pen receives pack, bridge executor applies schema and creates runtime receipts, product surfaces consume scores and actions.
