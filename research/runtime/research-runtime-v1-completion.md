# Research Runtime v1 Completion

Status: PARTIAL until live deployment and proof gates pass.

The model is now anchored around uncertainty, not documents.

Object chain:

Theme -> Question -> Uncertainty -> Hypothesis -> Activity -> Experiment -> Evidence -> Asset -> Product -> Revenue -> Claim -> Reuse

The dossier is a generated view over this graph. It is not the source of truth.

## Purpose

This runtime turns research activity into reusable business, product, commercial, and audit-ready objects.

Every asset must record:

- linked theme
- linked question
- linked uncertainty
- hypothesis
- activity
- experiment
- evidence
- result
- learning
- commercial path
- claim relevance
- reuse path

## Evidence grades

A: contemporaneous source evidence.
B: system generated support evidence.
C: reconstructed structured evidence.
D: unsupported narrative or memory.

Rule: D does not support A. A can support D.
