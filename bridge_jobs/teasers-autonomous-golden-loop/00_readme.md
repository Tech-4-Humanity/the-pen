# Teasers Autonomous Golden Loop

Status: PARTIAL until bridge execution receipt proves runtime.

Teasers is a browser-layer human effectiveness signal system. It is not a survey engine. It answers: when is a human actually effective?

Golden base:
- Browser runtime stays thin.
- Teasers runs as a pack/module.
- MCP Bridge handles execution and receipts.
- Supabase stores canonical signal data.
- Command Centre surfaces live status.
- Reality Ledger forces REAL only when runtime evidence exists.

Core loop:
1. Trigger from browser open, meaningful tab, cadence window, or behaviour signal.
2. Select one prompt from pulse, context, topical, reflection, or recovery classes.
3. Deliver one lightweight card with answer, snooze, or dismiss.
4. Capture answer, latency, device/session context, and interaction type.
5. Enrich with browser/session/context signals and optional wearable adapters.
6. Score Focus, Reactivity, Load, Control, Recovery, Movement, and Effectiveness.
7. Store records in Supabase and evidence ledger.
8. Activate feedback into Command Centre, AHC, WorkFamilyAI, HoloOrg, and downstream agents.
9. Evolve prompt timing, suppression, question quality, and intervention logic.

REAL gate:
- GitHub commit receipt exists.
- Bridge job receipt exists.
- Supabase tables exist.
- First delivery row exists.
- First response row exists.
- First score row exists.
- Command Centre widget is visible.
