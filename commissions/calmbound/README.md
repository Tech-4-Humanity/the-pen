## Governing rules

1. Household intent is translated into visible, temporary, reversible and accountable action.
2. Every capability must map to person, role, space, mode, agreement, permission, signal and evidence.
3. No action is REAL without execution, receipt, ledger entry, telemetry, validation and recovery.
4. No surveillance by default.
5. Child agency increases with maturity.
6. Partner access is narrow, purpose-bound, revocable and logged.
7. Stripe is a billing adapter; Supabase or another database is a persistence implementation. Neither is the platform centre.
8. Prior prototypes are reference evidence, not production foundations.
