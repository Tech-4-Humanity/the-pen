# CASCADE ISOLATION — failure containment doctrine\n\n**Created:** 2026-04-30  \n**Trigger:** operator caught false-clear pattern (archive != done) and called for explicit isolation rules\n\n## Three levels\n\n| level | scope | example | failure rule |\n|---|---|---|---|\n| **L1 within build** | one spec / one feature / one PR | SPEC-004 has 5 sub-tools | sub-task fail does NOT halt siblings unless **hard dep** (compile/runtime/correctness) |\n| **L2 across builds** | siblings in same repo or spec-family | SPEC-001 (DNS fix) + SPEC-004 (write tools) both in t4h-remote-mcp-server-clean | spec-A failure does NOT halt spec-B unless they touch same file/migration |\n| **L3 across orgs** | different credential silos / accounts | TML-4PM GH org vs T4H AWS account vs Supabase | org-scoped credential burn affects ONLY that org tooling |\n\n## Rules\n\n1. **A blocker has a scope.** Tag every blocker with isolation_level in {BUILD, REPO, ORG, GLOBAL}. Only GLOBAL halts everything.\n2. **Operator-only != blocker for agents.** A sub-task needing operator hands does NOT halt agent-doable parallel work. Track on its own tier=BLOCKED lane; sibling tracks proceed.\n3. **Hard dep vs soft dep.** Hard = recipient cannot ship without it. Soft = ship without, mark PARTIAL.\n4. **Archive requires proof.** A queue item enters archived only with: proof_ref IS NOT NULL OR payload.operator_reject=true OR payload.superseded_by=<job_id>. Never bare archive.\n5. **Freeze is repo-scoped, not global.** A freeze on repo X does not freeze repo Y.\n\n## Concrete examples from 2026-04-30 backlog\n\n| item | wrong cascade | right cascade |\n|---|---|---|\n| INCIDENT-001 (token burn) | halted SPEC-004 entirely | rotation track BLOCKED operator-only; build/audit/vault-plan/gating-verify tracks proceed in parallel |\n| SPEC-001 freeze | tied to PR#9 (SPEC-004) which got closed | SPEC-001 has its own branch fix/lazy-init-dns-cache; merge independently |\n| SPEC-004 5 tools | one tool blocked all | each tool ships independently with per-tool dry-run gate |\n| DRIVE-CLEANUP-V1 | indefinite "accepted" wait | blocked with explicit unblock signal — cleanly resumable |\n\n## Anti-patterns\n\n- Global FREEZE on one repo halting other repos\n- Operator-only sub-task halting agent-doable siblings\n- Token burn in one org halting work in another org\n- "Awaiting" as terminal state without expiry or explicit unblock signal\n- ARCHIVE used as "please go away" instead of "verifiably done"\n\n## Enforcement (next step)\n\n- ops.work_queue: add isolation_level text col; reject INSERT without it\n- ops.work_queue: trigger to reject status=archived without proof_ref / reject signal / supersedence\n- audit.receipts: every archive transition must reference at least one receipt\n- canonical_changes: BLOCKER changes must declare scope; only GLOBAL fans out alerts\n
