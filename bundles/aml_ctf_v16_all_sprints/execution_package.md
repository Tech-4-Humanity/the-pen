## Runtime doctrine applied

The sprint bundle uses these runtime rules:

- Capabilities are built as packages rather than individual files.
- Builders continue until the commissioned package is complete or blocked.
- Verification and receipts are mandatory.
- Executive output is a summary, not implementation logs.
- Common execution responsibilities belong to runtime services, not package code.
- Business functionality belongs in capability packages.
