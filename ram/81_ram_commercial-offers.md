> RAM is infrastructure first, offer second. External commercial offers below are listed for completeness but remain BLOCKED until dogfood completion proves the system on T4H's own data.

## Offer ladder

### Tier 1 — RAM Clean ($499)
- Asset normalisation only (filenames, manifests, sidecars)
- Output: organised folder + manifest + dedupe report
- Suitable for: consultants, tradies, small clinics, solo founders
- Status: BLOCKED until dogfood REAL

### Tier 2 — RAM Lift ($1,500)
- Adds documentation uplift (structural + context enrichment)
- Output: validated docs with purpose, owner, evidence state
- Suitable for: agencies, small NDIS providers, allied health practices
- Status: BLOCKED

### Tier 3 — RAM Portfolio ($3,500)
- Adds portfolio surface generation across audiences
- Output: executive/operational/partner-ready capability cards
- Suitable for: founder portfolios, partner submissions, advisory pitches
- Status: BLOCKED

### Tier 4 — RAM Operating Memory ($7,500)
- Full subscription with continuous janitor + watcher agents
- Output: live registry + portfolio + drift dashboards
- Suitable for: SMBs with messy 5+ year asset histories
- Status: BLOCKED

### Tier 5 — Enterprise / Government Knowledge Recovery (POA)
- Custom engagement: institutional memory recovery, evidence binding, governance proof
- Target: departments, councils, health providers, education bodies, compliance-heavy orgs
- Status: BLOCKED
