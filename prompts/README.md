# Canonical prompt contracts

Use `AGENT_PROMPT_COMPLETION_CONTRACT.md` for active end-state execution prompting. It begins with and requires the canonical five-line completion preamble from `global/AGENT_PROMPT_COMPLETION_PREAMBLE.md`.

`execution-contract-end-state.md` is legacy and must not be used as a canonical agent prompt unless/until it begins with the exact five-line preamble. Where the two conflict, `AGENT_PROMPT_COMPLETION_CONTRACT.md` wins.
