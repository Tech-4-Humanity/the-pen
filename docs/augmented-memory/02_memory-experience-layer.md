# Memory Experience Layer

The same memory graph can power multiple experience modes. These modes are optional front-end behaviours, not separate products.

## Core Modes

## Reflection Mode
Calm, private, story-led recall. Best for families, care, and remembrance.

## Discovery Mode
Explore memories connected to nearby places. Best for travel, venues, streets, museums, and public memory.

## Story Mode
Turns memory collections into readable or playable narratives.

## Timeline Mode
Chronological recall of moments, decisions, milestones, learning progress, or life events.

## Perspective Mode
Shows multiple memories about the same place, person, or event without forcing one official truth.

## Emotional Mode
Groups memories by feeling or state. Useful for guided reflection, wellbeing, and later specialist products.

## Ritual Mode
Surfaces memories on anniversaries, birthdays, family moments, and recurring cultural events.

## Companion Mode
An assistant that prompts, retrieves, and summarises memories at useful moments.

## Trails Mode
A sequenced path through place-based memories, for tourism, family routes, city walks, schools, and museums.

## Kids Visit Mode
Simplified, safer, lighter language and content controls for children.

## Public Light Mode
Allows optional public or anonymous memories without forcing identity exposure.

## Curated Mode
Partner or institution managed memory layers for venues, councils, museums, cemeteries, schools, and organisations.

## Build Rule
Do not expose every mode in MVP. Build mode flags and enable them by product, user type, partner type, and context.
