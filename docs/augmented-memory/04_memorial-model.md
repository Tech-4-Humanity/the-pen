# Memorial Model

## Overview
Supports tribute, remembrance, and respectful long-term memory storage tied to families and places.

## Models

### Partner Model
- funeral home onboarding
- cemetery linkage
- optional QR/NFC marker

### Family Model
- self-created memorial
- optional place link
- optional printed marker

### Virtual Model
- cemetery-level presence without precision
- plot precision added later

## Features
- tribute page
- timeline
- voice/video
- remembrance prompts
- family sharing
- public or private modes

## Rules
- private by default
- family conflict handled by content ownership
- no forced public exposure
