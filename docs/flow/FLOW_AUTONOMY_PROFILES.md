# FLOW Autonomy Profiles

FLOW autonomy profiles define how each business behaves inside the shared FLOW engine.

## Core idea

FLOW = engine
Profiles = behaviour

## Levels

- Manual
- Assisted
- Gated
- Autonomous
- Protected

Each business selects a profile.

## Purpose

Allows one system to run many businesses safely.

## Outcome

- fast where safe
- controlled where needed
- consistent everywhere
